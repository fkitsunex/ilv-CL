ILV-CL — I Like Vanilla: Colored Lighting

A fork of "I Like Vanilla" by What42Pizza (published with the author's permission), based on I Like Vanilla v1.4.0b,
adding a colored voxel-lighting system, Distant Horizons support and many lighting / reflection / fog fixes.
Every ILV-CL code change was written by Claude (Anthropic's AI); the fork's maintainer (Kukidoo) did not write any code.
